Type **/** at the start of a message to ask Ozni something common in one step. A menu opens above the message box. Keep typing to narrow it, use the up and down arrow keys or tap to choose, and press Enter. A built-in command is sent for you as your own message, so it appears in the chat and costs the same as if you had typed it. A saved prompt is put in the message box instead, so you can read it before you send it.

## The built-in commands

| Command | What it asks Ozni |
|---|---|
| **/today** | What is on today: appointments, your tasks and what needs attention |
| **/unsigned-notes** | Which clinical notes are still unsigned |
| **/low-stock** | Which items are low on stock or about to expire |
| **/reorder** | Draft a purchase order for what is running low |
| **/my-tasks** | Your open tasks |
| **/week-report** | A summary of the last seven days |
| **/help** | What Ozni can help you with |

A command only appears when it can work for you. If your plan, your edition or your role does not include the screen behind a command, the command is not in the menu. For example, **/low-stock** does not appear if you cannot open Inventory.

## Saved prompts

Your clinic can save its own common questions. They appear in the same menu, under the built-in commands.

<Path steps={['Settings', 'Ozni Assistant', 'What Ozni remembers', 'Saved prompts']} />

Everyone at the clinic can see the saved prompts. Owners and managers select **Add a saved prompt**, give it a short name and write the question, then select **Save**. Select **Edit** or **Delete** on a prompt to change it. A clinic can keep up to 30.

<Warning>
A saved prompt is a question anyone could send. Don't put a client's or a colleague's name or details in it. If a prompt looks like it mentions a person or personal details, it is not saved and you are told why.
</Warning>

A saved prompt is only words in your message box until you send it, and then it is sent as your message. It never changes what Ozni is allowed to do, and it cannot give Ozni new rules.
